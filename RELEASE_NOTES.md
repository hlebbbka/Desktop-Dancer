# Desktop Dancer 1.0

## English

First public release for Windows 10/11 x64.

- Bass-reactive dancing characters, jumps and flips.
- Duets and four-beat Dance-battle with smooth handovers.
- Equalizer, particles, bass glow, chromatic aberration and a wandering or mouse-controlled trail.
- Sustained bass keeps the wandering trail accelerated.
- Desktop pet, fullscreen, themes and custom character images.
- Spotify track title, rounded album artwork, estimated BPM and windowed lyrics with synchronization status.
- Russian and English interface with a saved language preference.
- The default character is the cat in a suit.

**Install:** download `DesktopDancer-1.0-win-x64.zip`, extract everything and run `Start.cmd`. .NET is included. Microsoft Edge WebView2 Runtime is required if not already installed.

## Русский

Первый публичный релиз для Windows 10/11 x64.

- Танцующие персонажи с реакцией на бассы, прыжками и сальто.
- Дуэты и Dance-battle по четыре доли с плавной передачей очереди.
- Эквалайзер, частицы, свечение от басса, хроматическая аберрация и гуляющий шлейф или шлейф от мыши.
- Ускорение гуляющего шлейфа сохраняется во время продолжительного басса.
- Питомец, полный экран, цветовые темы и свои изображения.
- Название трека и скруглённая обложка из Spotify, определение BPM и текст песни в оконном режиме со статусом синхронизации.
- Русский и английский интерфейс с сохранением выбранного языка.
- Стартовый персонаж — кот в деловом костюме.

**Установка:** скачайте `DesktopDancer-1.0-win-x64.zip`, распакуйте целиком и запустите `Start.cmd`. Среда .NET включена. Если Microsoft Edge WebView2 Runtime отсутствует, его нужно установить отдельно.

`SHA256SUMS.txt` contains the archive checksum / содержит контрольную сумму архива.
